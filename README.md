# WarungSpot: Satu Foto, Langsung di Peta 🗺️📱

![WarungSpot Banner](https://img.shields.io/badge/WarungSpot-UMKM%20Platform-orange?style=for-the-badge)
![Next.js](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)
![Supabase](https://img.shields.io/badge/Supabase-PostgreSQL-green?style=for-the-badge&logo=supabase)

**WarungSpot** adalah platform AI yang membantu UMKM mendigitalkan toko mereka secara instan. Cukup upload **satu foto spanduk**, AI kami akan mengekstrak data (Nama, No HP, Kategori) dan mendaftarkannya ke peta interaktif.

---

## 🚀 Quick Start

1.  **Clone & Install**
    ```bash
    git clone https://github.com/santosssaja/warungspot.git
    cd warungspot
    npm install
    ```

2.  **Setup Environment**
    Copy `.env.example` ke `.env.local` dan isi credentials Supabase & AI API Key.

3.  **Run**
    ```bash
    npm run dev
    ```
    Buka [http://localhost:3000](http://localhost:3000).

👉 **Panduan Setup Lengkap**: [docs/SETUP.md](docs/SETUP.md)

## ✨ Fitur Utama

-   **📸 Instant Onboarding**: Upload foto, AI yang mengisi formulir.
-   **🤖 AI Analysis**: Ekstraksi teks cerdas menggunakan Kolosal AI / OpenAI.
-   **🗺️ Interactive Map**: Peta berbasis OpenStreetMap untuk eksplorasi toko.
-   **🔐 Secure**: Autentikasi dan otorisasi aman dengan Supabase.
